# Lidia García — Developer Portfolio

### Full Stack Developer Portfolio

Personal portfolio showcasing my work as a Full Stack Developer, with a focus on building digital products from real-world problems.

The portfolio brings together my main projects, technical case studies and development approach, with particular interest in **B2B applications, internal tools and Healthcare Tech**.

🌐 **Live:** https://portfolio-lidia-one.vercel.app

---

## About the Portfolio

This portfolio was designed and developed from scratch as the central showcase for my work.

Rather than presenting projects only as screenshots or repository links, the portfolio focuses on explaining the reasoning behind each product: the problem, users, technical decisions, architecture, challenges and results.

The experience includes:

- Personal introduction and developer profile
- Technical skills and technologies
- Featured Full Stack projects
- Detailed project case studies
- Responsive interface
- Spanish / English experience
- Contact and professional links

## Featured Projects

### Flowly

**Healthcare Authorization Management Platform**

A B2B application inspired by real operational processes in the healthcare insurance sector.

Flowly transforms complex healthcare authorization workflows into a structured, traceable and role-based digital process.

**Stack:** React · Next.js · Node.js · Express · MongoDB · REST APIs

[Repository](https://github.com/lidiaaire/flowly) · [Case Study](https://portfolio-lidia-one.vercel.app/projects/flowly)

---

### Elevate

**Learning Management System**

A Full Stack LMS designed around the experience of students, teachers and administrators.

It includes course progression, assessments, progress tracking, certificates, achievements and role-based access.

**Stack:** Next.js · React · Node.js · Express · MongoDB

[Repository](https://github.com/lidiaaire/elevate-campus) · [Case Study](https://portfolio-lidia-one.vercel.app/projects/elevate)

## Design Approach

The visual system follows a dark, editorial interface with a strong focus on typography, hierarchy and project presentation.

Key design principles include:

- Clear visual hierarchy
- Content-first project presentation
- Reusable UI patterns
- Responsive layouts
- Consistent project identities
- Accessible and readable interfaces
- Minimal visual noise

## Local Development

Clone the repository:

```bash
git clone https://github.com/lidiaaire/portfolio-lidia.git
cd portfolio-lidia
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

Create a production build:

```bash
npm run build
```
